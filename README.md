# Task Manager JS

Aplicación de gestión de tareas desarrollada con HTML, CSS y JavaScript Vanilla.

## Características

- Agregar tareas
- Completar tareas
- Eliminar tareas
- Filtrar tareas
- Persistencia con LocalStorage
- Diseño responsive

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Conceptos implementados

### Manipulación del DOM
Uso de:
- querySelector
- createElement
- addEventListener
- innerHTML
- appendChild

### Persistencia de datos
Implementación de LocalStorage para mantener las tareas guardadas incluso después de recargar la página.

### Responsive Design
Diseño adaptable para dispositivos móviles y escritorio utilizando Flexbox y medidas responsivas.
