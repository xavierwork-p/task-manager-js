# Task Manager App

Aplicación de gestión de tareas desarrollada con HTML, CSS y JavaScript.

## Características
- Agregar tareas
- Completar tareas
- Eliminar tareas
- Filtrar tareas
- Persistencia con LocalStorage
- Diseño responsive

## Tecnologías
- HTML5
- CSS3
- JavaScript
